1.2 赋范线性空间及内积空间

习题 11. 设 (X,∥⋅∥) 是赋范线性空间. 如果对 X 中任意元素 x,y, 都成立平行四边形公式∥x+y∥2+∥x−y∥2=2(∥x∥2+∥y∥2),那么可以在 X 中定义内积 ⟨⋅,⋅⟩, 使得 ∥⋅∥ 是由内积 ⟨⋅,⋅⟩ 诱导的范数.

证明.

(1)

若 X 是实线性空间:
定义B(x,y)=∥x+y∥2−∥x−y∥2和内积⟨x,y⟩=41​B(x,y).下面验证 ⟨⋅,⋅⟩ 确实是 X 上满足 ∥x∥2=⟨x,x⟩ 的内积.
对称性: B(y,x)=∥y+x∥2−∥y−x∥2=∥x+y∥2−∥x−y∥2=B(x,y).正定性: ⟨x,x⟩=41​(∥2x∥2−∥0∥2)=∥x∥2,所以 ⟨x,x⟩≥0, 且等号成立当且仅当 x=0, 正定性成立.
下面验证线性性: 对任意 u,v,z∈X, 由平行四边形公式, B(u+v,z)+B(u−v,z)​=∥u+v+z∥2+∥u−v+z∥2−∥u+v−z∥2−∥u−v−z∥2=2∥u+z∥2+2∥v∥2−2∥u−z∥2−2∥v∥2=2B(u,z).​又因为B(−u,z)=∥u−z∥2−∥u+z∥2=−B(u,z),所以对 x,y,z∈X, 4(⟨x,z⟩+⟨y,z⟩)​=B(x,z)+B(y,z)=21​(B(x+y,z)+B(x−y,z))+21​(B(x+y,z)+B(y−x,z))=B(x+y,z)=4⟨x+y,z⟩.​这证明了第一变量的可加性. 对任意正整数 n, 由可加性, ⟨nx,z⟩=n⟨x,z⟩.结合 ⟨0,z⟩=0 和 ⟨−x,z⟩=−⟨x,z⟩, 得到对任意 m∈Z, 都有 ⟨mx,z⟩=m⟨x,z⟩. 再对任意正整数 n, 有n⟨nm​x,z⟩=⟨mx,z⟩=m⟨x,z⟩,因此⟨rx,z⟩=r⟨x,z⟩,∀r∈Q.由于范数连续, x↦B(x,z) 连续. 对任意 t∈R, 取有理数列 rn​→t, 则∥rn​x−tx∥=∣rn​−t∣∥x∥→0,从而⟨tx,z⟩=n→∞lim​⟨rn​x,z⟩=n→∞lim​rn​⟨x,z⟩=t⟨x,z⟩.因此线性性成立, 故 ⟨⋅,⋅⟩ 是满足所需条件的内积.

(2)

若 X 是复线性空间:
仍令B(x,y)=∥x+y∥2−∥x−y∥2.定义内积⟨x,y⟩=41​(B(x,y)+iB(x,iy)).类似实的情况可知, B(x,y) 对第一变量具有实线性, 因此 ⟨x,y⟩ 对第一变量也具有实线性.

计算可知 B(ix,y)=−B(x,iy),B(ix,iy)=B(x,y). 于是4⟨ix,y⟩​=B(ix,y)+iB(ix,iy)=−B(x,iy)+iB(x,y)=4i⟨x,y⟩.​可知第一变量的复线性成立.

又由 B(y,x)=B(x,y) 和 B(y,ix)=B(ix,y)=−B(x,iy), 得到4⟨y,x⟩​=B(y,x)+iB(y,ix)=B(x,y)−iB(x,iy)=4⟨x,y⟩​.​这证明了共轭对称性.

最后, 由于 B(x,ix)=∥(1+i)x∥2−∥(1−i)x∥2=0, 故⟨x,x⟩=41​B(x,x)=41​∥2x∥2=∥x∥2.所以 ⟨x,x⟩≥0, 且等号成立当且仅当 x=0. 故 ⟨⋅,⋅⟩ 是满足所需条件的内积.

□

1.3 Hilbert 空间的正交系

习题 3. 令 L2([0,2π]×[0,2π]) 上的内积为⟨f,g⟩=∬[0,2π]×[0,2π]​f(x,y)g(x,y)​4π2dxdy​.证明: {eimxeiny:m,n∈Z} 构成 L2([0,2π]×[0,2π]) 的一组标准正交基.

证明.

方法一.

我们证明一个更一般的结论.

定理 1.1. 设 (X,F,μ) 和 (Y,G,ν) 是两个 σ-有限的测度空间, {en​}n∈N​ 和 {fm​}m∈N​ 分别是 L2(X,μ) 和 L2(Y,ν) 的一组标准正交基, 则 {(x,y)↦en​(x)fm​(y)}m,n∈N​ 是 L2(X×Y,μ×ν) 的一组标准正交基. 这里 X×Y 上的 σ-代数可以取 F⊗G, 也可以取它关于 μ×ν 的完备化.

证明. 由 Fubini 定理, 对任意 m,m′,n,n′∈N, 有⟨en​fm​,en′​fm′​⟩L2(X×Y)​=⟨en​,en′​⟩L2(X)​⟨fm​,fm′​⟩L2(Y)​=δnn′​δmm′​.因此 {en​fm​} 是标准正交系. 下面证明它的完全性.

设 h∈L2(X×Y,μ×ν) 满足⟨h,en​fm​⟩L2(X×Y)​=0,∀m,n∈N.由 Tonelli 定理, 对几乎所有 x∈X, 都有 h(x,⋅)∈L2(Y,ν). 对每个 m, 在这些 x 上定义am​(x)=∫Y​h(x,y)fm​(y)​dν(y),并在余下的零测集上令 am​(x)=0. 由 Cauchy–Schwarz 不等式, ∣am​(x)∣2≤∫Y​∣h(x,y)∣2dν(y),故 am​∈L2(X,μ). 再由 Fubini 定理, 对所有 n 都有⟨am​,en​⟩L2(X)​=⟨h,en​fm​⟩L2(X×Y)​=0.因为 {en​} 是标准正交基, 所以 am​=0 a.e., 即存在零测集 Nm​, 满足 am​(x)=0,∀x∈X\Nm​. 由于 m 只有可数多个, 可以取同一个零测集 N=∪m​Nm​⊆X, 使得对任意 x∈X∖N 和任意 m∈N, 都有⟨h(x,⋅),fm​⟩L2(Y)​=am​(x)=0.再由 {fm​} 的完全性, 对任意 x∈X∖N, 在 L2(Y) 中有 h(x,⋅)=0. 于是由 Tonelli 定理, ∥h∥L2(X×Y)2​=∫X​∥h(x,⋅)∥L2(Y)2​dμ(x)=0.从而 h=0 a.e., 完全性得证.

□

4.

约定所有的环都不是零环且含有幺元.

5.

Z,Q,R,C 分别表示整数环、有理数域、实数域和复数域.

1.

(20 分) 设 D 是可除环, M 是左 D-模. 证明 M 是自由模.

2.

(20 分) 考虑环 R=Q×Q, I={(a,0)∣a∈Q}, J={(0,b)∣b∈Q}. 证明:

(i) I,J 是 R 的理想. 作为 R-模, 问 I 与 J 是否同构? 说明理由.

(ii) 设 Q∗=Q−{0} 是有理数乘法群. 作为 Z-模, 问 Q∗ 是否为平坦模? 说明理由.

3.

(20 分) 设 F 是域, 考虑 M4​(F) 中的矩阵A=⎝⎛​0001​1000​0100​0010​⎠⎞​,B=⎝⎛​1000​1100​0110​0011​⎠⎞​问 A,B 在 M4​(F) 中是否相似? 说明理由.

4.

(20 分) 设 R 是主理想整区, n 是正整数, Rn 是秩为 n 的自由模, M 是 Rn 的一个子模. 若存在 Rn 的子模 T 使得 Rn=M⊕T, 则称 M 是 Rn 的直和项.

(i) 证明: M 是 Rn 的直和项当且仅当商模 Rn/M 是无挠的 (torsion-free).

(ii) 若两个不同的子模 M,N 都是 Rn 的直和项, 则 M∩N 是否也是 Rn 的直和项? 说明理由.

5.

(20 分) 设 R 是交换环, I 是 R 的理想. 若 R/I 是平坦 R-模, 证明: I=I2.

1随机矩阵的定义及基本性质

设 K=R 或 C.

(Matn​(K),∥⋅∥op​): 取 K 值的的 n 维矩阵空间. ∀X∈Matn​(K),∥X∥op​=sup{∥Xv∥,v∈Kn,∥v∥=1}.这里 ∥⋅∥: Kn 上的范数, ∥⋅∥op​: 算子范数. Xm​→X,m→∞,即Xm​(i,j)→X(i,j),m→∞X∗ 为 X 的伴随 (adjoint) (当 K=R 时, X∗=XT; 当 K=C 时, X∗=(Xˉ)T) .

若 X=X∗, 则称 X 为自伴的 (self adjoint).

SMatn​(K): Matn​(K) 中自伴矩阵全体, 是 Matn​(K) 中的闭子集.

定义迹运算: ∀X∈Matn​(K),Tr(X)=t=1∑n​X(t,t).

引理 1.1. 迹运算在是 (Matn​(K),∥⋅∥op​) 中的连续线性泛函, 且满足以下性质:

∀X,S∈Matn​(K),S 可逆,Tr(X)=Tr(SXS−1)

引理 1.2. ∀X∈SMatn​(K), 存在可逆矩阵 S, 使得X=S diag(λ1∗​,…,λn∗​)S−1,其中λ1∗​≤⋯≤λn∗​.

定理 1.3. ∀n∈N, X,Y∈SMatn​(K), 有i=1∑n​(λiX​−λiY​)2≤Tr[(X−Y)∗(X−Y)]=Tr[(X−Y)2]

推论 1.4. n∈N, l∈{1,…,n}, 映射

Eigl​:SMatn​(K)X​→R↦λXl​​

是连续的.

证明. 设 (Xm​) 和 X 是 SMatn​(K) 中的元素, 且 Xm​m→∞​X, 则∣λlXm​​−λlX​∣2≤l=1∑n​∣λlXm​​−λlX​∣2≤Tr(Xm​−X)2m→∞​0

定义 1.5. (Ω,A,P) 是概率空间, n∈N. 则一个 n 阶自伴随机矩阵是一个可测映射X:(Ω,A)→(SMatn​(K),BS(n2)​)这里 BS(n2)​ 表示 SMatn​(K) 上的 Borel σ-代数.

注 1.6. 映射可测 ⇔ 每个 X(i,j):(Ω,A)→(K,B) 可测.

今后提及 “随机矩阵” 不加强调时一般均表示自伴随机矩阵.

若 X 是 (Ω,A,P) 上的随机矩阵, 则 ∀ω∈Ω, X(ω)∈SMatn​(K), 且有特征值 λ1X(ω)​≤…≤λnX(ω)​.

引理 1.7. X 是 (Ω,A,P) 上的 n 阶随机矩阵, 则映射λiX​:(Ω,A)ω​→(R,B)↦λiX(ω)​​是可测的, 即 λlX​ 是实值随机变量.

证明.

Eigl​:SMatn​(K)→R, X↦λlX​ 连续, 而 X:Ω→SMatn​(K) 可测. 故二者复合 λlX​=Eigl​∘X 可测.

□

Wn​=(n​1​Xn​(i,j))i,j=1n​, 若 Xn​(i,j) 满足

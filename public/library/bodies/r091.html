附录 C Stone–Weierstrass 定理

习题 4. 对紧度量空间 X, 设 A 是实值连续函数空间 C(X) 中分离 X 中点的闭子代数. 证明: A=C(X) 或存在一点 x0​∈X 使得A={f∈C(X):f(x0​)=0}.

证明. A 离 Stone–Weierstrass 定理的条件就相差个含单位元了, 因此可以发现 {g+c:g∈A,c∈R} 就是 C(X). 下面分两种情况讨论.

如果存在一点 x0​∈X 使得对 A 中的函数 g 均有 g(x0​)=0, 那么对 f∈C(X) 且 f(x0​)=0, 设 f 可写成 g+c, 由 x0​ 处的取值得到 c=0, 即 f=g, 也就是 f∈A, 这表明 A={f∈C(X):f(x0​)=0}.

如果不存在这样的点 x0​, 即 X 有开覆盖 g∈A⋃​{g=0}, 就有有限子覆盖 i=1⋃k​{gi​=0}, 那么 h=i=1∑k​gi2​ 是恒正的. 令 j=h/∥h∥∈A, 记 δ=Xmin​j>0, 则 ∥(1−j)n∥=(1−δ)n→0, 故 A 中的序列 1−(1−j)n 收敛于 1, 从而 1∈A, 进而 A=C(X).

□

习题 5. 对于 Banach 空间C0​(R)={f 在 R 上连续:∣x∣→∞lim​f(x)=0},设 A 是 C0​(R) 中的自伴闭子代数, 分离 R 中的点, 并在任意点 x∈R, 有 f∈A 使得 f(x)=0. 证明: A=C0​(R).

证明. 这次的问题在于 R 不是紧集, 那么可以单点紧化成单位圆周 T. 考察同构映射Ψ:C0​(R)f​→B={g 在 T∖{−1} 上连续:w→−1lim​g(w)=0},↦g, 其中 f(tanθ)=g(ei2θ),​后者相当于 B′={g 在 T 上连续:g(−1)=0}. 由条件可得 Ψ(A) 是 C(T) 中分离点的自伴闭子代数, 结合上题知 Ψ(A)=B′, 从而 A=C0​(R).

□

附录 D 弱拓扑中的一些定理

习题 1. 设 X 是 Banach 空间, γ⩾0, f1​,⋯,fn​ 是 X 上的 n 个有界线性泛函, α1​,⋯,αn​ 是 n 个给定的数. 那么对于任意的 ε>0, 存在 xε​∈X 使得fi​(xε​)=αi​ (i=1,2,⋯,n),以及∥xε​∥⩽γ+ε的充要条件是不等式∣∣​i=1∑n​βi​αi​∣∣​⩽γ∥∥​i=1∑n​βi​fi​∥∥​对于任意的 n 个数 β1​,⋯,βn​ 都成立.

证明. 设前一条件成立, 那么对于任意的 ε>0, ∣∣​i=1∑n​βi​αi​∣∣​=∣∣​(i=1∑n​βi​fi​)(xε​)∣∣​⩽(γ+ε)∥∥​i=1∑n​βi​fi​∥∥​,令 ε→0+ 即得.

先假定 f1​,⋯,fn​ 线性无关. 设前一条件不成立, 即存在 ε>0 使得 α 不属于 f(Bγ+ε​), 其中 α=(α1​,⋯,αn​)∈Rn, f=(f1​,⋯,fn​):X→Rn. 那么存在一个超平面分离 α 与 f(Bγ+ε​), 换言之存在非零的 (β1​,⋯,βn​)∈Rn 使∣∣​i=1∑n​βi​fi​(x)∣∣​⩽∣∣​i=1∑n​βi​αi​∣∣​对所有 ∥x∥⩽γ+ε 成立, 故有(γ+ε)∥∥​i=1∑n​βi​fi​∥∥​⩽∣∣​i=1∑n​βi​αi​∣∣​.由于 ∥∥​i=1∑n​βi​fi​∥∥​>0, 后一条件不成立.

对一般的情况, 取 f1​,⋯,fn​ 的一个极大的线性无关子集即可.

习题 1. 设 X 是不可分 Banach 空间, T∈B(X). 证明: 存在 X 的一个非平凡闭子空间 M 使得 TM⊆M.

证明. 设 x 是 X 的任何非零元素, 令 M 为 {x,Tx,T2x,⋯} 生成的子空间的闭包.

□

注. 事实上, T 不存在非平凡闭不变子空间当且仅当对所有的 x, {x,Tx,T2x,⋯} 生成的子空间稠密.

习题 2. 叙述 X=Cn 时的定理 F.1, 并给出直接的证明.

定理 F.1′ 设 T 是 Cn 上的非零算子. 那么, 存在 Cn 的一个非平凡子空间 M, 对于每个与 T 交换的算子 S 都有: S(M)⊂M.
证明. 取 T 的一个特征子空间 ker(T−λI) 为 M 即可, 对 x∈M, (T−λI)Sx=S(T−λI)x=0, 即 Sx∈M.

□

习题 3. 设 R({x1​,x2​,⋯})={0,x1​,x2​,⋯} 是 l2 上的右移位算子, T 是 l2 上的紧算子. 若 TR=RT, 证明: T=0.

证明. 对任何 x∈l2, 序列 {Rnx} 在 n→∞ 时弱收敛于 0, 那么 {TRnx} 收敛于 0, 即 {RnTx} 收敛于 0. 由于 R 是等距映射, 必有 Tx=0.

□

注. [Ha] 问题 148 (pp.79 & 271–2) 表明, 本题如果不假定 T 是紧算子, 那么 T 是一列 R 的多项式 {pn​(R)} 的强算子极限.

附录 G C∗ 代数与正规算子谱理论

习题 1. 设 A={(a0​ba​):a,b∈C} 为 M2​(C) 的 Banach 子代数, 求 A 的非零可乘线性泛函.

解答. 设 ϕ 是 A 上的非零可乘线性泛函, 记 Q=(00​10​), 注意到ϕ(Q)2=ϕ(Q2)=ϕ(0)=0,即 ϕ(Q)=0. 由于 dimkerϕ=dimA−1=1, 得出 kerϕ=CQ, 从而ϕ(a0​ba​)=a.□

习题 2. 对于带单位元的 Banach 代数 A, 若 A 的极大理想空间能分离 A 中元素: 若 a=b, 则有可乘线性泛函 ϕ 使得 ϕ(a)=ϕ(b). 证明 A 是交换 Banach 代数.

证明. 重述一下条件: 若对所有的可乘线性泛函 ϕ 都有 ϕ(a)=ϕ(b), 则 a=b. 既然如此, 对任意的 x,y∈A, 由于对所有的可乘线性泛函 ϕ 都有 ϕ(xy)=ϕ(yx), 那么 xy=yx.

□

习题 3. 设 C(1)[0,1]={f∈C[0,1]:f 在 [0,1] 上连续可导}, 其上范数定义为∥f∥=x∈[0,1]sup​(∣f(x)∣+∣f′(x)∣).证明: C(1)[0,1] 依此范数构成 Banach 代数. 并求 C(1)[0,1] 的极大理想空间.

解答. 是全体 {f∈C(1)[0,1]:f(x0​)=0}, 其中 x0​ 取遍 [0,1]. 方法同例 G.1.

习题 5. 下面来看 L1(R) 的极大理想空间和 Gel’fand 变换.

(i)

令 R 为赋予加法结构的实数群, T={z∈C:∣z∣=1} 为赋予乘法运算结构的酉群. 若连续群同态 h:R→T 不是常值映射, 证明: 加法子群 h(−1)({1}) 为 R 的离散子集. 并说明 h(−1)({1})∖{0} 到点 0 距离严格大于 0 且是可达的.

(ii)

令 R^={h:h 是从 R 到 T 的连续群同态}. 证明: R^={ht​(x)=eitx:t∈R}. 并且证明 R^ 在乘法作用 (h1​×h2​)(x)=h1​(x)h2​(x) 下构成乘法群.

(iii)

任取一个 h∈R^. 证明: ϕ(f)=∫R​f(x)h(x)​dm(x)为 Banach 代数 L1(R) 上非零可乘线性泛函.

(iv)

设 ϕ:L1(R)→C 是 L1(R) 上非零可乘线性泛函. 证明: 存在 h∈L∞(R) 使得ϕ(f)=∫R​f(x)h(x)​dm(x),且对几乎处处 x,y∈R, 有 h(x+y)=h(x)h(y).

(v)

为说明 (iv) 中 h 的连续性, 对 (iv) 中的 ϕ, 取定一个 g∈L1(R),ϕ(g)=1. 证明: h(x)=ϕ(g(⋅−x)) 对几乎处处 x∈R 成立.

(vi)

证明 (iv) 中 h∈R^.

证明. 本题表明, L1(R) 的 Gel’fand 变换就是 R 上的 Fourier 变换.

(i)

R 的子群有聚点的话就是稠密的, 因此 R 的闭子群除了本身均是离散的.

(ii)

h 是群同态就是说 h(x+y)=h(x)h(y), 两边对 y 求导再取 y=0, 得出 h′(x)=h(x)h′(0), 从而 h(x)=eh′(0)x. 取值范围是 T 进一步要求 h(x)=eitx, 其中 t∈R.

不过刚才假定了 h 是可导的, 这一点是有待说明的. 为此, 取 h 的原函数 g(t)=∫0t​h, 由于 h(0)=1, 取定很小的 δ>0 会使得 g(δ)>0, 则有h(x)=g(δ)g(x+δ)−g(x)​,右边分子是可导的且分母是常数, 从而左边亦是可导的.

(iii)

设 h(x)=eitx, 那么ϕ(f∗g)​=∫R​[∫R​f(x−y)g(y)dy]e−itxdx=∫R​[∫R​f(x−y)e−it(x−y)dx]g(y)e−itydy=ϕ(f)ϕ(g).​

(iv)

ϕ 属于 L1(R) 的对偶空间, 对应着 L∞(R) 中的函数 h. 比较一下ϕ(f∗g)​=∫R​[∫R​f(x−y)g(y)dy]h(x)​dx=∫R​∫R​f(x)g(y)h(x+y)​dxdy,​和ϕ(f)ϕ(g)​=[∫R​f(x)h(x)​dx][∫R​g(y)h(y)​dy]=∫R​∫R​f(x)g(y)h(x)h(y)​dxdy,​得到 h(x+y)=h(x)h(y) 几乎处处成立.

(v)

由于ϕ(g(⋅−x))=∫R​g(y−x)h(y)​dy,得到ϕ(f∗g)=∫R​f(x)ϕ(g(⋅−x))dx.ϕ(g)=1 说明 ϕ(f∗g)=ϕ(f), 这样上式同ϕ(f)=∫R​f(x)h(x)​dx比较, 就得出 h(x)​=ϕ(g(⋅−x)) 几乎处处成立.

(vi)

结合前两问得出 h 是 R 到 C 的连续群同态, 还要说明的是 ∣h(x)∣=1. 这是因为对任何整数 n, 都有 ∣h(x)∣n=∣h(nx)∣⩽∥h∥∞​.

□

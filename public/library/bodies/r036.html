1集合的势

p13.16. 设集合 B 与 C 的并的势是 ℵ, 证明: B 与 C 其中有一个集合的势为 ℵ, 进一步地, 如果 n=1⋃∞​An​ 的势为 ℵ, 证明至少存在一个 Ak​ 的势是 ℵ. (使用选择公理, 且避免使用连续统假设)

证明. 直接证明第二问. 注意到: ℵℵ0​=2ℵ0​∗ℵ0​=2ℵ0​=ℵ, 故可以构造一个一一映射 π:[0,1]N→n=1⋃∞​An​.

反设 An​​​<ℵ,∀n∈Z+​, 则 ∀n∈Z+​, 必然存在 αn​∈[0,1], 使得 En​:={(x1​,⋯,xn−1​,αn​,xn+1​,⋯)∣xk​∈[0,1]} 满足 π(En​)∩An​=∅. (否则构造投射 pn​:An​→[0,1], 便有 An​​​≥[0,1]​​=ℵ, 矛盾!)

在这种构造下, 考虑 (α1​,α2​,⋯)∈[0,1]N, 有 π((α1​,α2​,⋯))∈/An​,∀n∈Z+​, 这与 π 是 [0,1]N 与 n=1⋃∞​An​ 之间的一一映射矛盾!

□

2测度的定义与性质

p42.12. 考虑如下的几个集合: X={x=(x1​,x2​,⋯)∣n=1∑∞​xn​​<+∞,xn​=n2j​(j=0,1,2,⋯,n2)}.

对于 x∈X, [x]n​={y∈X∣y1​=x1​,⋯,yn​=xn​}, 称为 n 级集. Rn​ 为所有 n 级集生成的 σ 环, μn​ 是 Rn​ 上满足μn​([x]n​)=i=1∏n​1+i21​的测度.

(a) 写出 Rn​ 的元素的形式, 以及 μn​ 在 Rn​ 上的定义.

(b) 证明: R1​⊆R2​⊆⋯, 且 R:=n=1⋃∞​Rn​ 是一个环.

(c) 若 n<m, 求证: 对任意 E∈Rn​, 均有 μm​(E)=μn​(E).

(d) 如下定义 R 上集函数 μ: 对于 E∈Rn​, 令 μ(E)=μn​(E), 求证: μ 满足有限可加性, 但是不满足可列可加性.

证明. (a) Rn​ 中元素为: ∅ 或 [x1,x2,⋯,xk]n​:={y∈X∣y1​=x1j​,⋯,yn​=xnj​,∃j∈{1,⋯,k}}, 其中 x1,⋯,xk 为 X 中的 k 个不同元素.

测度 μn​ 的严格表示为 μn​([x1,x2,⋯,xk]n​)=k⋅i=1∏n​1+i21​.

(b) 对于每一个 n∈Z+​, 只需要证明: Rn​⊆Rn+1​.

∀[x1,x2,⋯,xk]n​∈Rn​, 取 xs,j=(x1s​,x2s​,⋯,xns​,j,⋯),j=0,1,⋯,(n+1)2.

则 [x1,x2,⋯,xk]n​=[x1,0,x1,1,⋯,x1,(n+1)2,⋯,xk,(n+1)2]n+1​∈Rn+1​, 故 R1​⊆R2​⊆⋯.

欲证 R 是一个环, 只需验证有限交和有限并的封闭性. ∀v1​,v2​∈R, 必有 v1​∈Rn1​​,v2​∈Rn2​​ 对某 n1​,n2​∈Z+​, 且不妨设 n1​≤n2​. 此时 v1​∈Rn1​​⊆Rn2​​, 因此 v1​∪v2​∈Rn2​​,v1​∩v2​∈Rn2​​.

(c) 由于测度的可列可加性, 只需验证测度在生成元上相等, 即只需验证 μn+1​([x]n​)=μn​([x]n​).

由 (b),[x]n​=[x0,x1,⋯,x(n+1)2]n+1​, 故 μn+1​([x]n​)=((n+1)2+1)⋅i=1∏n+1​1+i21​=i=1∏n​1+i21​=μn​([x]n​).

(d)∀v1​,v2​∈R, v1​∩v2​=∅, 必有 v1​∈Rn1​​,v2​∈Rn2​​ 对某 n1​,n2​∈Z+​, 且不妨设 n1​≤n2​. 则 v1​,v2​∈Rn2​​,

因此 μ(v1​∩v2​)=μn2​​(v1​∩v2​)=μn2​​(v1​∩v2​)+μn2​​(v1​∩v2​), 这验证了 μ 具有有限可加性.

反设 μ 具有可列可加性, 则 μ 是测度, 考虑取 vn​=[x1,⋯,xN]n​, x1,⋯,xN 为 X 中全体前 n 个分量不等于 0 的元素. 则 μn​(vn​)=N⋅i=1∏n​1+i21​=i=1∏n​i2⋅i=1∏n​1+i21​=i=1∏n​1+i2i2​. 且有 v1​⊇v2​⊇⋯,μ(v1​)<∞.

故由测度的性质, μ(i=1⋂∞​vi​)=iinf​μ(vi​)=ninf​i=1∏n​1+i2i2​=i=1∏+∞​1+i2i2​.

由简单的分析估计, logi=1∏+∞​1+i2i2​=i=1∑+∞​log1+i2i2​≥i=1∑+∞​(1−i21+i2​)=−i=1∑+∞​i21​=−6π2​.故 μ(i=1⋂∞​vi​)>0.

但是 i=1⋂∞​vi​=∅. (每个分量均为正的元素必定有 i=1∑+∞​xn​​=+∞, 故不属于 X.) 矛盾!

因此 μ 不具有可列可加性.

3测度的扩张

13. 设 E 是 R 的子集, 若对任意 x∈R, 存在 rx​>0, 使得 m∗((x−rx​,x+rx​)∩E)=0, 证明:m∗(E)=0.

证明. 证明: 反设 m∗(E)>0, 由 Stein Chapter.1 Ex.28 得到: 存在闭区间 I, 使得 m∗(I∩E)>0. 由条件, 对任意 x∈I, 存在 rx​>0, 使得 m∗((x−rx​,x+rx​)∩E)=0,

由实数的有限覆盖定理, 存在覆盖 x∈I⋃​(x−rx​,x+rx​)⊇I 的有限子覆盖 i=1⋃n​(xi​−rxi​​,xi​+rxi​​)⊇I.

故 m∗(I∩E)≤m∗(i=1⋃n​(xi​−rxi​​,xi​+rxi​​)∩E)≤i=1∑n​m∗((xi​−rxi​​,xi​+rxi​​)∩E)=0. 矛盾!

4可测集的结构

13. 设 E,F 是直线中的子集, 证明: m∗(E∩F)+m∗(E∪F)≤m∗(E)+m∗(F).

证明. 取 E∩F⊂G 使得 m(G)=m∗(E∩F),G 是 Lebesgue 可测集. 由 Carathéodory 条件: ⎩⎨⎧​m∗(E)m∗(F)m∗(E∪F)​=m∗(E∩G)+m∗(E\G),=m∗(F∩G)+m∗(F\G),=m∗((E∪F)∩G)+m∗((E∪F)\G).​(E∪F)\G=(E\G)∪(F\G),m∗((E∪F)\G)≤m∗(E\G)+m∗(F\G).

m∗(E∩F)≤m∗(E∩G),m∗(F∩G),m∗((E∪F)∩G)≤m∗(G)=m∗(E∩F).

126 春 (江智)

1.

For a finite Abelian group A, prove that Hom(A,Q/Z)≃A. If for finite Abelian groups A,A′,A′′ we have an exact sequence 0⟶A′⟶A⟶A′′⟶0,then we have 0⟶A′′⟶A⟶A′⟶0.

2.

For an Abelian group A, we say A is a whitehead group if Ext1(A,Z)=0. Prove that if A is a whitehead group, then a subgroup of A is still a whitehead group. Also prove that if A is a torsion group, then Ext1(A,Z)≃Hom(A,S1), where S1 is the circle group. So if A is a non-zero torsion group, A is not a whitehead group.

3.

Find out free, projective, injective and free Z-module in the following four Z-modules: Z,Z/mZ,Q,Q⊕Z.

4.

Let R be a commutative Noetherian ring and M,N be two finitely generated R-modules. Prove that TorkR​(M,N) is a finitely generated R-module for arbitrary k. Calculate Tor1R​(R/I,R/J) for ideals I,J of R. If ann(M)+ann(N)=R, prove that TorkR​(M,N)=0 for arbitrary k.
